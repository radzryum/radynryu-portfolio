CYMON — Updated System Architecture (Figure 25 replacement)

ClearMind Psychological Services (CMPS) · Three-Tier · matches current code: React 19 + Express 5 + Supabase · open this file in any browser to view/print

TIER 1 — PRESENTATION TIER (Frontend)

React 19 + Vite 8 + Tailwind CSS v4 · React Router 7 · Recharts · Lucide · react-hot-toast · pdfjs-dist · Supabase JS session client · SPA on Vercel · /api/* via Vite proxy (dev) / rewrite (prod)
Public LandingShaderGradient / Three.js hero, Specialties scrollytelling, Announcements carousel, dark/light toggle, hamburger menu (mobile).
Auth UILogin (email or CMPS-XXXX-XXX + password), Remember me, Forgot password → Send OTP → Verify OTP (10 min) → Reset password.
Client PortalHome & Progress trackers, Daily Journal log, Assessment Services (Start / Download PDF), Appointments (Upcoming/Past, Join Telehealth), Consents & Waivers e-sign, Announcements.
Psychologist DashboardTasks, Students roster (Support Level, Milestone slider), Intake Interview (1/student), Approvals (View / Approve / Request Revision / Reject), Daily Activity Report, Monthly Report (Generate / Export PDF), Student Journal.
Psychometrician DashboardTask list, Student Roster (read-only), Assessment Services (Assign / Answer Likert, Save Progress / Submit), FO-03/FO-04 Scoring Guide (read-only suggestion), IEP Workspace (Create / Add Goal / Request Co-Sign), Attendance, Monthly draft, Student Journal.
Admin / Super Admin DashboardOverview charts, Students (Register / Archive / Restore / Admission Slip PDF), Employees (Add / Manage Roles / Deactivate / Reactivate), Compliance, Front Desk schedule, Attendance (Present/Late/Absent), Clinical Records, Content Manager, Announcements, Audit Trail (append-only + CSV export for Super Admin).
▼ HTTPS (TLS at platform) · JSON / multipart — fetch('/api/...') ▼

TIER 2 — APPLICATION TIER (Backend)

Node.js + Express 5 (CommonJS) · app.js → routes → middleware/requireAuth → lib/* · local :4000 / Vercel serverless · DTO whitelisting (lib/dto.js), central error middleware
Edge / Cross-cuttingCORS allowlist + credentials, express.json 10mb, express.raw ONLY for /api/payments/webhook/paymongo (HMAC verify), 404 JSON, error → next(err).
Security & Authmiddleware/requireAuth.js: Supabase Auth getUser(Bearer) → profiles (role + extra_roles + x-active-role + deleted_at deactivation check). No custom JWT, no Multer.
Routes (controllers)/api/auth, /public, /client, /admin, /psychologist, /psychometrician, /notifications, /payments, /cron/reminders (x-cron-secret), /health. Role checks via lib/permissions.js; writes logged via lib/audit.js.
Serviceslib/email.js (Resend prod + Nodemailer dev fallback), lib/notify.js, lib/paymongo.js, lib/appointments.js, lib/documentReleases.js, cron reminder job (23–24h window, reminder_sent flag).
PDF pipelinepdf-lib generate · pdf-parse read · pngjs signatureInk recolor · pdfWatermark · formPdf / formLayouts / assessmentSchemas / dynamicFO03 / dynamicFO05 / behavioralReport / assessmentReleaseSlipPdf.
▼ Supabase client over HTTPS/443 (PostgREST + Storage API + Auth API) · Resend / PayMongo HTTPS REST ▼

TIER 3 — DATA TIER + EXTERNAL SERVICES

Supabase (Postgres + Auth + Storage) · Resend · PayMongo · Vercel Cron — no raw TCP from app code, no WAF/API-gateway code in repo (handled by host)
Supabase Postgres (RLS)profiles, patients, appointments, assessments, reports, session_logs, journals, IEPs, waivers, announcements, document_releases, notifications, audit_trail (UPDATE/DELETE blocked by trigger; service-role write, admin read).
Supabase AuthEmail/password + session tokens; OTP password-reset; deactivation via profiles.deleted_at / patient archive propagates to login block.
Supabase StorageClinical PDFs, announcement images, avatars — signed URLs / streaming over HTTPS.
Resend (prod) / Nodemailer SMTP (dev)Welcome, OTP, appointment reminders, notifications. Gmail-API note in STACK.md is aspirational — code uses Resend + Nodemailer.
PayMongoPayment links + raw-body webhook with HMAC signature verification.
Vercel Cron → /api/cron/remindersSends unscheduled reminder emails; guarded by x-cron-secret, not user auth.
▲ DTO-whitelisted encrypted JSON returns → React renders (Recharts charts, task badges, PDF iframe desktop / pdfjs image mobile) ▲
